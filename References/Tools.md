# Geospatial & AI Tools Directory

This document lists developer libraries, CLI tools, geospatial processing engines, and agent frameworks used in research.

---

## 🛠️ Geospatial Libraries & Frameworks

- **Rasterio**: https://rasterio.readthedocs.io/ – Fast, idiomatic geospatial raster I/O for Python.
- **GDAL (Geospatial Data Abstraction Library)**: https://gdal.org/ – Translator library for raster and vector geospatial data formats.
- **Shapely**: https://shapely.readthedocs.io/ – Manipulation and analysis of geometric shapes in Cartesian plane.
- **GeoPandas**: https://geopandas.org/ – Extends Pandas data structures to support spatial operations.
- **PyProj**: https://pyproj4.github.io/pyproj/ – Python interface to PROJ cartographic projections.
- **TorchGeo**: https://torchgeo.readthedocs.io/ – PyTorch domain library for remote sensing and geospatial data loaders.
- **TiTiler**: https://developmentseed.org/titiler/ – Dynamic Cloud Optimized GeoTIFF tile server.

---

## 🤖 Agentic & Model Serving Tools

- **LangGraph**: https://langchain-ai.github.io/langgraph/ – Cyclic multi-agent graph orchestrator.
- **vLLM**: https://vllm.ai/ – High-throughput and memory-efficient LLM inference engine.
- **Ollama**: https://ollama.com/ – Get up and running with LLaVA and large language models locally.
- **OpenCV**: https://opencv.org/ – Open Source Computer Vision Library.
- **MapLibre GL JS**: https://maplibre.org/ – Open-source WebGL interactive map client.
