# SIH Submission Guidelines

This document tracks standard Smart India Hackathon submission procedures, expected artifacts, and compliance rules.

---

## 📑 1. Standard Deliverables

1. **Idea / Approach PPT**:
   - Standard SIH prescribed format (approx. 7–10 slides).
   - Problem statement background, proposed solution, technical architecture, novel differentiators, feasibility, and team details.

2. **Video Demonstration**:
   - Concise demonstration video showcasing end-to-end capabilities (e.g. natural language query $\to$ multi-step agentic execution $\to$ visual evidence + textual answer + trace).
   - Clear audio narration and clear depiction of remote sensing use cases.

3. **Software Architecture & Technical Documentation**:
   - High-level system architecture, data flow diagrams, agent execution loops.
   - Evidence-grounding methodology and confidence estimation frameworks.

---

## 📋 2. Compliance Checklist

- [ ] Problem Statement ID (26167) clearly highlighted across all deliverables.
- [ ] Explicit alignment with ISRO requirements (Optical + SAR, Change Detection, VQA, Agentic Workflow).
- [ ] Open-source licensing compliance for all third-party models and datasets.
- [ ] Proper citation of scientific papers and benchmark sources.
- [ ] No proprietary ISRO sensitive or classified data used without authorization.
