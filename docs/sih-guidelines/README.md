# 02 - SIH Guidelines

## 📌 Purpose
This directory organizes all official guidelines, submission standards, evaluation rubrics, judging criteria, and milestone timelines for the **Smart India Hackathon (SIH) 2026**.

---

## 📂 Contents

| File | Description |
| :--- | :--- |
| [`Submission-Guidelines.md`](Submission-Guidelines.md) | Official SIH submission requirements, presentation formats, deliverable expectations, and compliance rules. |
| [`Judging-Criteria.md`](Judging-Criteria.md) | Detailed breakdown of the multi-round judging rubric, evaluation weightages, and key differentiators. |
| [`Important-Dates.md`](Important-Dates.md) | Key milestones, internal preparation deadlines, hackathon schedule, and deliverable checkpoints. |

## 🎯 What Belongs Here
- SIH official submission templates, presentation deck formats, video demo criteria.
- Judging rubrics and scoring weightages.
- Hackathon timeline, phase deadlines, and review schedules.

## 🚫 What Does NOT Belong Here
- Technical research papers or deep learning model specs (use [`04-Research-Papers/`](../04-Research-Papers/README.md) or [`05-Models/`](../05-Models/README.md)).
- Problem-specific ISRO requirements (use [`01-Problem-Statement/`](../01-Problem-Statement/README.md)).

## 👥 How Team Members Should Use This
- Review before preparing milestone presentations, pitch decks, architecture diagrams, or final demonstration videos to ensure full compliance with SIH standards.
