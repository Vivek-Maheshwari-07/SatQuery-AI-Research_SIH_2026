# Team Research Notes

## 📌 Purpose
This directory stores exploratory research notes, quick experiments, paper highlights, and individual investigation logs written by team members.

---

## 📝 Format for Adding a Research Note
Create a file using the format: `YYYY-MM-DD-Topic-Author.md`

Include:
1. **Topic / Focus Area**
2. **Author**
3. **Core Insights**
4. **Key Questions / Blockers**
5. **Next Steps**
