# BigEarthNet Resources & References

## 🔗 Official Links
- **Official Website**: https://bigearth.net/
- **Official Documentation**: https://bigearthnet-models.readthedocs.io/
- **TorchGeo Integration**: https://torchgeo.readthedocs.io/en/stable/api/datasets.html#bigearthnet

## 🛠️ Relevant Tools & Scripts
- `torchgeo.datasets.BigEarthNet`: Pre-built PyTorch dataset loader for automated downloading and spectral band stacking.
- `rasterio` / `gdal`: Reading and processing multi-band GeoTIFF tiles.

## 📄 Benchmark References
- Sumbul et al., *"BigEarthNet-MM: A Large-Scale, Multimodal, Multilabel Benchmark Dataset for Remote Sensing Image Analysis"*, IEEE Transactions on Geoscience and Remote Sensing (TGRS).
