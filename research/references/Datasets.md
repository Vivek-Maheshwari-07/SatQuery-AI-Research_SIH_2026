# Master Datasets Directory

This document provides a master directory of open-access remote sensing datasets, benchmarks, and data portals.

---

## 🗂️ Benchmark Datasets

| Dataset | Modality | Primary Task | Access Link |
| :--- | :--- | :--- | :--- |
| **BigEarthNet-MM** | Sentinel-1 SAR & Sentinel-2 Optical | Multi-Label LULC Classification | https://bigearth.net/ |
| **VRSBench** | Optical Aerial / Satellite RGB | VQA, Visual Grounding, Scene Captioning | https://github.com/Visual-RS/VRSBench |
| **RSVQA** | Sentinel-2 (LR) & Aerial (HR) | Remote Sensing VQA | https://rsvqa.sylvainlobry.com/ |
| **CDVQA** | Dual-Date Optical Pairs | Change Detection VQA | https://github.com/Bob-Z/CDVQA |
| **LEVIR-CD / LEVIR-CD+** | Bi-Temporal High-Resolution Optical | Building Change Detection | https://justchenhao.github.io/LEVIR/ |
| **SpaceNet (1-8)** | Multi-spectral, SAR, Optical | Building/Road Extraction, Flood Assessment | https://spacenet.ai/ |
| **DOTA (1.0 / 1.5 / 2.0)** | Aerial Optical | Oriented Object Detection | https://captain-whu.github.io/DOTA/ |
