# Remote Sensing Visual Question Answering (RS-VQA)

## 📌 Purpose
This directory organizes research papers focusing on question-answering systems tailored for Earth Observation and aerial imagery.

---

## 🎯 What Belongs Here
- Papers on RS-VQA methodologies, including classification-based VQA, generative VQA, and open-vocabulary VQA.
- Works addressing counting, spatial relationships, and small-object detection in remote sensing QA.
