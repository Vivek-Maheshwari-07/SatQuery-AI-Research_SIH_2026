# Visual Grounding in Remote Sensing

## 📌 Purpose
This directory organizes research papers on text-guided localization, referring expression comprehension, and open-vocabulary object detection in remote sensing imagery.

---

## 🎯 What Belongs Here
- Papers covering referring expression grounding (e.g., GeoRSGround, RSVGD, Grounding DINO adaptation for aerial imagery).
- Studies on fine-grained spatial localization from overhead perspectives.
