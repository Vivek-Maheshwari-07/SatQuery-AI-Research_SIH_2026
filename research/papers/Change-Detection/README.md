# Remote Sensing Change Detection & Change-VQA

## 📌 Purpose
This directory organizes scientific literature on bi-temporal change detection, change captioning, and conversational change-based visual question answering.

---

## 🎯 What Belongs Here
- Papers on deep change detection architectures (Siam-Conc, BIT, ChangeFormer, TinyCD, ChangeCLIP).
- Research on Change Captioning (generating sentences explaining changes between time $T_1$ and $T_2$).
- Conversational bi-temporal reasoning and Change-VQA benchmarks.
