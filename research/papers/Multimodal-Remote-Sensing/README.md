# Multimodal Remote Sensing Literature

## 📌 Purpose
This directory organizes general literature on multimodal Earth observation, multi-spectral band alignment, hyperspectral analysis, and geospatial representation learning.

---

## 🎯 What Belongs Here
- Papers on multimodal foundation models (e.g., CROMA, Clay, Prithvi, SatMAE, DOFA).
- Studies covering cross-sensor domain adaptation and multi-temporal self-supervised pre-training.
