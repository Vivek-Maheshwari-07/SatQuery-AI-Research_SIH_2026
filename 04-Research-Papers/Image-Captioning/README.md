# Remote Sensing Image Captioning

## 📌 Purpose
This directory organizes research papers dedicated to generating rich, coherent natural language descriptions of satellite and aerial scenes.

---

## 🎯 What Belongs Here
- Papers on RS image captioning benchmarks (Sydney-Captions, UCM-Captions, RSICD, NWPU-Captions).
- Encoder-decoder architectures, multi-scale feature aggregation, and attention-based scene description models.
